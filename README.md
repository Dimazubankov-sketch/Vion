# Vion

Мессенджер в стиле X (Twitter) и Telegram. Светло-серый интерфейс, фиолетовый
акцент Vion. Next.js 16 (App Router) + TypeScript + Tailwind v4 +
`react-aria-components` + `@remixicon/react`.

## Запуск

```bash
npm run dev
```

Открой http://localhost:3210 (порт задан в `.claude/launch.json`; обычный
`next dev` поднимется на 3000).

Авторизация замокана: на экране входа введи любой email и пароль (8+ символов) —
или зарегистрируйся. Сессия хранится в `localStorage`, «Sign out» — в боковом меню.

## Возможности

- **Лента** — поиск вверху, посты с локацией и датой, галерея фото, стопка
  лайкнувших, счётчик просмотров, лайк, репост и разворачиваемые комментарии.
- **Чаты** — личные и **групповые**, поиск, вложения по кнопке «+» (фото/видео
  или документ), **голосовые сообщения** с живой волной от реального микрофона.
- **Звонки** — аудио и видео, а прямо в звонке — мини-игры: камень-ножницы-бумага,
  крестики-нолики, четыре в ряд и «правда или ложь» (по мотивам Honk).
- **Профиль** — подписки/подписчики, вкладки «Посты» и «Репосты», кнопка «+» для
  публикации, редактирование описания, аватара и обложки.
- **История** — все посты, которые вы лайкнули.
- **Настройки** — язык интерфейса (English, Русский, Español, Deutsch, Français),
  тема и переключатели приватности.
- **Вход** — регистрация требует почту **и** телефон, вход — почту **или** телефон.
  Номер подтверждается кодом из SMS.
- **Адаптация под ПК** — на широком экране постоянное боковое меню, а чат
  показывает список и переписку в двух колонках.

> Демо-код подтверждения — `123456` (SMS-шлюза в сборке нет).
>
> Голосовые и видеозвонок требуют разрешения на микрофон/камеру. Если доступ
> запрещён — показывается понятное сообщение вместо ошибки.

## Навигация

- **Нижняя панель** — 3 вкладки: Home (лента), Notifications, Messages (чат).
- **Аватар слева вверху** (или иконка меню) → боковое меню.
- В боковом меню **карточка пользователя** или пункт **Profile** → профиль.
- В чате: поиск → список чатов → тап по чату открывает переписку (с отправкой).

## Заметки

- Компоненты BoardUI Pro (`AuthCard`, `DashboardSidebar`, `SettingsModal` и др.)
  требуют платной лицензии Pro и тянут десятки внутренних зависимостей, поэтому
  здесь они воссозданы самостоятельно в том же стиле — проект запускается без Pro.
- Фирменный знак Vion — `public/vion-logo.png` (он же фавикон, `src/app/icon.png`).
  Чтобы обновить логотип, замени эти два файла.
- Аватары/фото — заглушки с `i.pravatar.cc` и `picsum.photos` (нужен интернет).
