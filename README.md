# Voyzen

Мессенджер в стиле X (Twitter) и Telegram. Светло-серый интерфейс, фиолетовый
акцент Voyzen. Next.js 16 (App Router) + TypeScript + Tailwind v4 +
`react-aria-components` + `@remixicon/react`.

## Запуск

```bash
npm run dev
```

Открой http://localhost:3210 (порт задан в `.claude/launch.json`; обычный
`next dev` поднимется на 3000).

Авторизация замокана и работает локально. Сначала зарегистрируйся: имя, логин
(домен `@voidops.ru` подставится сам), телефон и пароль от 8 символов, код
подтверждения — `123456`. Потом входи по логину и паролю или по номеру.
Сессия хранится в `localStorage`, «Выйти» — в боковом меню.

```

    accounts.ts           # локальный реестр аккаунтов @voidops.ru

    i18n.ts               # словари: en, ru, es, de, fr
    app-store.tsx         # общее состояние: посты, чаты, история лайков

  components/

    app/
      app-shell.tsx       # оболочка: шапка, вкладки, нижняя навигация, оверлеи
      feed.tsx            # лента: поиск-шапка, кнопка «+»
      post-card.tsx       # пост: лайк, репост, просмотры, комментарии с ответами
      post-composer.tsx   # публикация: галерея, камера, опрос, место, GIF
      poll-chart.tsx      # опрос: полосы или кольцевая диаграмма
      history.tsx         # понравившиеся посты

      call.tsx            # аудио/видеозвонок, полный экран, сворачивание, игры

      sidebar.tsx         # меню: drawer со свайпом, сворачиваемый рельс на ПК

      edit-profile.tsx    # редактирование профиля (описание, фото, обложка)
      settings.tsx        # настройки, включая выбор языка
    base/
      input.tsx           # поле ввода с состояниями (в т.ч. невалидное + тряска)
      input-otp.tsx       # поле кода подтверждения
      phone-input.tsx     # телефон с выбором страны (флаги + коды)
    ui/
      avatar.tsx          # аватар с онлайн-точкой
      loader.tsx          # анимация «Configuring your account…» (motion)
  utils/
```

## Возможности

- **Лента** — поиск вместо шапки, посты с локацией и датой, галерея фото,
  лайкнувшие, просмотры, лайк, репост и кнопка «+» для публикации.
- **Комментарии** — сортировка по новым и популярным, ответы на чужие
  комментарии, лайки, а через «+» — фото, документы и ссылки в ответе.
- **Публикация** — галерея, снимок с камеры, опрос, местоположение и GIF.
  У опроса на выбор два графика результатов: полосы или кольцо.
- **Чаты** — личные и групповые, вложения по «+», **голосовые и видеосообщения**:
  тап по кнопке переключает голос ↔ видео, удержание записывает, движение вверх
  закрепляет запись.
- **Звонки** — аудио и видео (камеру можно включить в любом звонке), полный
  экран, смена основного окна, **сворачивание** — звонок продолжается фоном,
  пока вы пользуетесь чатом. Внутри звонка мини-игры: камень-ножницы-бумага,
  крестики-нолики, четыре в ряд и «правда или ложь».
- **Профиль** — подписки/подписчики, вкладки «Посты» и «Репосты», кнопка «+»,
  редактирование описания, аватара и обложки.
- **История** — все посты, которые вы лайкнули.
- **Настройки** — язык (English, Русский, Español, Deutsch, Français), тема,
  **мобильный вид на ПК** и приватность.
- **Вход** — аккаунты на домене `@voidops.ru`: домен подставляется сам, при
  регистрации проверяется занятость имени, при неверном входе поле краснеет и
  вздрагивает. Регистрация требует почту и телефон, вход — почту или телефон.
- **Звуки** — синтезируются на лету через Web Audio (отправка, звонок, запись,
  победа/поражение в игре, ошибка). Отключаются в настройках.
- **Адаптация под ПК** — постоянное боковое меню (сворачивается в иконки) и чат
  в две колонки. На мобильном меню открывается и закрывается свайпом.

## Заметки

- Компоненты BoardUI Pro (`AuthCard`, `DashboardSidebar`, `SettingsModal` и др.)
  требуют платной лицензии Pro и тянут десятки внутренних зависимостей, поэтому
  здесь они воссозданы самостоятельно в том же стиле — проект запускается без Pro.
- Фирменный знак Voyzen — `public/voyzen-logo.png` (он же фавикон, `src/app/icon.png`).
  Чтобы обновить логотип, замени эти два файла.
- Аватары/фото — заглушки с `i.pravatar.cc` и `picsum.photos` (нужен интернет).
- GIF добавляется по ссылке: встроенный поиск требует ключа Giphy или Tenor.
- Библиотека звуков Honk Sounds с benji.org помечена «© Aave Labs, All Rights
  Reserved» — чужие проприетарные ассеты, поэтому в проекте не используются.
